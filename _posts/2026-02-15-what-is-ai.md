# What is the hype of AI all about?

## You've heard a lot about "AI", "Agents", "machine learning", "artificial intelligence", and the like. What do you need to know?

### What does it all mean?

Let's start with "machine learning": the definition is a software system that uses statistics-based algorithms to model a set of data and learn from it. "Learn" in this context means to take a whole lot of data that has been structured in a way to make the different instances similar in form and create an algorithm that predicts missing elements. 

There's a whole lot of math behind it— if you learned any linear algebra in high school or college, it might even be familiar. The data is vectors, the learning is a matrix, the prediction is multiplying a new vector by the matrix, and the resulting output is another vector.

That's a mouthful. What does it mean? 

The input data— the "vector"— is a list of information. Maybe, for instance, the list of scores that a team has had in its games this season. That's an example— take "what has happened previously" and "what happened afterwards" and then take "for this case, what just happened" and "predict what happens next". "Sports score" is a simple example; an obvious similar one would be stock prices. Or, given the weather yesterday here and around me, what's the weather tomorrow? Or, given that someone just wrote the previous two sentences and three words, what are they likely to write next?

The learning— the "matrix"— is a way to take that list of data and predict, from that, its score in the next game.

Is it perfect? No. Especially when you're looking at things like scores of games or stock prices, there's no real ability to predict. What it is, is a system based on "with what's happened before, what's likely to happen next?"

That's why a lot of people (unnecessarily dismissively, in my opinion) call them "just auto correct". It's also why they're used for helping you write— "given what has been written so far, what's the next word that makes sense to add to the document?"

Perfect? No. But... pretty good for a lot of things. And it gets better if you use more data and if the data stays kind of inside a boundary that helps make each one more predictable.

So what ML is really good at is: taking a new case that's similar to old cases and using the old cases to predict a result for the new case; taking a bunch of cases and grouping them or clustering them together by similarity; learning from existing cases and... extracting information.

### So, what's Artificial Intelligence?

AI is ML... and more. Where ML is more or less algorithmic, AI adds to it some components, that may themselves be based on ML, but provide additional functionality.

  * Use natural language processing— both to help analyze the data that it's looking at and allow users to ask about the data, the clustering, the predictions, and the information extracted by asking questions in plain English (or, you know, whatever your language of choice is). 
  * Decision support tools that help the AI make decisions based on inputs to the machine learning it's using.
  * Use of neural networks— essentially, computer software that is, itself, trying to act in a way similar to our brain cells in how they connect to each other to improve the machine learning.

Put it all together? AI is trying to leverage a deep understanding of data sets—combined with tools similar to human learning and language—to allow systems to perform tasks.

Generative AI— the stuff we're using nowadays to create images (and video!), documents (write me a murder mystery but do it in the style of SpongeBob SquarePants), and software (go create Microsoft Word but add in functionality to pull text directly from Wikipedia)— is all of that. But it also has a focus on learning from underlying data that is similar to what it's creating (every image that can be found on the internet; the full works of Agatha Christie and also the Cartoon Network; openly readable code for word processing software and also software that reads the Wiki). 

So create the underlying machine learning model using the data that's relevant (or, in the case of generalist AI, all the data you can get your hands on). Then tune it— have it generate results and give it feedback on how to improve it— which will cause the AI to change the prediction engine (that "matrix") that was created in the learning mode. 


### Agents? What role do they play?

Take your AI system and add functionality to perform workflows, step-by-step. For instance, follow a workflow to plan out how to write a piece of software— that's a "planning agent". Or "go through my email and schedule meetings"— that's a "scheduling agent". 

Some agents are being created by the AI companies to assist users directly. Anthropic, for instance, creates a bunch of agents for software developers to use in their Claude Code product.

Software developers are all-in on the whole agent thing— agents to design software, plan out how to build it, review the plan, build the software, test the software, document the software. Which, more or less, is what you'd expect. People who write software write agents to help them write software. Right?

But end users are creating their own agents, too, based on their specific workflows.
  * Create a personal assistant agent that works every morning to summarize emails, list calendar appointments, determine work priority
  * An agent used for answering standard emails requesting... work, or documents, or information about your company
  * An agent that searches the web or reviews articles in RSS feeds or checks social media to look for mentions of you or your company or your products and competitors
  * Search travel websites, book flights and cars and hotels and whole vacations, given my personal preferences

Again— software developers are creating their own agents. But companies are also springing up to create agents for people and make tools to allow them to create and modify agents. The broad category is "No-Code AI Agent Builders" or "AI Agent Platforms and Builders".

Agents are AI with workflows but also some amount of autonomy. They can be programmed to check back with the user; they may ask for feedback or specific instructions; and they might generate summaries of what they do to allow for corrections. But, fundamentally, they do things without requiring a lot of hands-on effort— and, hopefully, less intervention from a human the more they've done the task and received feedback.


### So— putting it all together?

We're using machine learning to both understand information that's out there and learn how to work with it.

One large area of machine learning is natural, human language: what people mean when they use words in specific ways.

We're structuring how we're using those learnings and using the natural language learning to allow people to use the machine learning in an easy and natural fashion. We're specializing the things that the software can do based on what people need. That's one way to look at a large piece of artificial intelligence.

Finally, we're using the AI and training it to perform specific tasks. We're using repeatable workflows as part of that task-doing. That then creates an AI Agent or Agentic AI tool that can be used to do things quickly, efficiently, and repeatably.
